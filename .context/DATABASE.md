# DATABASE INSTRUCTIONS

## USE SUPABASE
- Use supabase as the database for this project
- Download Supabase CLI and use it for this project.

## SETUP
- Setup database using supabase CLI
- Database name is: FretFlow
- Create a .env template for the supabase
- Duplicate and use it as the .env file
- Place the credentials and secret keys inside .env

## IMPORTANT!!!
- DO NOT USE SQLite AS THE DATABASE FOR THIS PROJECT
