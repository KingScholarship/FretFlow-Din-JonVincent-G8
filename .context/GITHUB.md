
# GITHUB Instructions

## Implementing a Feature / App

### Branch
- Make sure to branch out in this format: `<feature-name>`
- Only implement the app related to the branch

### Commit
- Commit using this message format: `<content-type>: <short description>`

## Merging

- Make sure to merge (fix the conflicts first) using this message: `<feature-name>: <short description>`
